## Birthday Wish Webpage

A beautiful, animated birthday wish webpage for Harshwardhan with interactive features and a stunning UI!

### ✨ Features

- 🎂 **Animated Birthday Cake** with bounce effect
- 🔥 **Flickering Candles** on top of the cake
- 🎈 **Floating Balloons** animation
- 🎊 **Confetti** falling effect
- ✍️ **Add Wishes** - Interactive wish input form
- 💾 **Local Storage** - Wishes are saved in browser
- 📱 **Mobile Responsive** - Works perfectly on all devices
- ✨ **Beautiful Animations** - Smooth transitions and effects
- 🌈 **Colorful Design** - Gradient backgrounds and vibrant colors

### 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript
- **Animations:** CSS Keyframes
- **Storage:** LocalStorage (Browser)
- **Responsive:** Mobile-first design

### 🚀 How to Use

1. **Open the webpage** - Simply open `index.html` in your browser
2. **View the cake** - Watch the animated birthday cake with bouncing effect
3. **Add wishes** - Type your birthday wish and click "Add Wish"
4. **Press Enter** - You can also press Enter to add wishes quickly
5. **Enjoy confetti** - Every wish adds celebratory confetti animation

### 📱 Mobile Features

- ✅ Fully responsive design
- ✅ Touch-friendly buttons
- ✅ Optimized for all screen sizes
- ✅ Smooth animations on mobile

### 🎨 Customization

To customize the webpage:

1. **Change the title:** Edit the `<h1>` in `index.html`
2. **Change colors:** Modify the gradient in `body` CSS in `style.css`
3. **Change cake colors:** Edit `.cake-layer-1`, `.cake-layer-2`, `.cake-layer-3` backgrounds
4. **Change animations:** Adjust the animation values in `style.css`

### 📝 Pre-loaded Wishes

The webpage comes with 4 default wishes:

### 💾 How Wishes are Stored

- Wishes are automatically saved to browser's LocalStorage
- They persist even after closing the browser
- No backend/database needed (optional)
- Clear browser storage to reset wishes

### 🔧 Optional: Add MongoDB Backend

To add MongoDB support for storing wishes on a server:

1. Create a Python Flask backend
2. Connect to MongoDB
3. Create API endpoints for saving/retrieving wishes
4. Update JavaScript to call API endpoints instead of localStorage
